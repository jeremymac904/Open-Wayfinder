# Exercise demos

The exercise library is in development. Jeremy's existing Noah and Isa drafts and source videos are held privately for review. No exercise GIF is included here yet.

A demo is ready for library use only after the exact clip's form and visual quality have been reviewed and the owner has approved it. Record source and reuse permissions. Do not imply a pending clip is approved. For unilateral movements, use real takes of both sides rather than mirroring.

When ready, each catalog entry should include exercise, variation, performer, version, video and GIF paths, review status, reviewer, date and provenance. Keep source video and looping GIF together. An unavailable clip must not be replaced by a fabricated link.
