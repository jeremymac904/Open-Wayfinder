# Contributing

Thanks for helping make Open Wayfinder useful and accessible.

1. Open an issue describing the problem or suggestion before a large change. Use fictional examples.
2. Keep instructions clear, platform-neutral where possible, and honest about tool access and limitations.
3. Never include private profiles, client records, passwords, personal photos, or copyrighted material without permission.
4. Preserve the coaching and crisis boundaries in [Privacy and safety](docs/privacy-and-safety.md).
5. Check links, test any examples you change, and describe what was actually tested in your pull request.

A license has not yet been selected, so the project's contribution and reuse terms remain to be established. Please don't submit code or materials until those terms are clarified.
