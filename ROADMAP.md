# Roadmap

This is a living roadmap, not a promise of delivery dates.

## Available: initial draft instructions

- Personal coach persona, private profile and check-in templates.
- Coaching skill instructions covering fitness, food, recovery, goals, mood, relationships, career, money, creativity, personal playbooks and more.
- Business assistant builder and marketing, operations, sales and research role prompts.
- Provider-documentation-based platform guides for ChatGPT, Claude, Gemini, Cursor, Microsoft 365 Copilot and local models.
- A local [check-in dashboard](tools/check-in-dashboard/README.md) for optional daily ratings and 7/14/30-day summaries; core and simulated UI checks pass, real-browser testing remains outstanding.
- A local [workout tracker](tools/workout-tracker/README.md) with private browser storage and JSON backup; core and simulated UI checks pass, real-browser testing remains outstanding.
- A dated [platform capability guide](docs/platform-connectors.md) and a three-times-weekly review scheduled by the project owner.
- MIT license, contribution guidance and issue templates.

These files are usable as copyable instructions, but have not yet been verified through end-to-end user workflows on each host. They are not installed bots, integrated services, or autonomous software.

## In development / planned

- End-to-end testing and improved setup across platforms, including actual file read/write and user-approved integrations.
- Extend the basic local workout tracker and check-in dashboard, connect approved data sources where supported, and finish real-browser and platform testing.
- Expanded Isa and Noah coach options with visual assets, and a reviewed public exercise demo library. Basic fictional coach-name instructions are available. Draft source videos and GIFs are held privately; inclusion requires version-specific review and appropriate rights.
- Additional exercise GIFs and stretches after source footage, movement variants and review status are established.
- Richer assistant workflows, examples, knowledge templates and tested integrations.
- Walkthrough videos, GitHub Projects and expanded contributor documentation.

A scheduled review can research platform changes; it is not proof a run succeeded or that an integration works. See issues for current work.
