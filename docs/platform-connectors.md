# Platform capability guide

Latest targeted review: 2026-11-20 (America/New_York).

This matrix records **provider-documented capability**, not proof that a particular account has the feature, is connected, or completed a working workflow. Availability can depend on plan, region, age, client, workspace policy, administrator settings, rollout status, model, and the connected service's own permissions.

## Status language

- **Announced:** the provider has documented a planned or rolling change; do not treat it as usable until it appears in the target account.
- **Available:** provider documentation says the feature is offered to the stated audience.
- **Installed:** the host has loaded the app or skill. **Connected:** the host has authorization for a specific service account. Both require private confirmation.
- **Tested:** a specific end-to-end workflow was run successfully. No end-to-end host test is recorded for the adapters below as of this review.
- **Unknown / stale:** the source did not establish the answer or the entry has not been rechecked on the date shown.

## What Open Wayfinder can safely promise

1. The Markdown persona, templates and skills can be copied or installed on compatible hosts.
2. The kit can describe a read/write workflow, but only the host, connector and user-granted permissions can execute it.
3. A file upload is usually a snapshot or knowledge source. Treat it as live and writable only after a permitted read, update, read-back and revocation test.
4. “Proactive” means scheduled or event-driven only where the target account actually supports it; otherwise use the manual morning and evening rituals.
5. Never put credentials, private journals, health records, borrower information or customer data in this public repository.
