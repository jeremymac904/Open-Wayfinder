# Onboarding

Use the [coach persona](../../persona/PERSONA.md). Ask one question at a time; let the user skip or pause.

1. Ask what they want help with first and what a good outcome would look like.
2. Ask what has worked for them and any constraints they want you to know. Do not solicit sensitive details unnecessarily.
3. Suggest one achievable action and a check-in rhythm the host actually supports.
4. Offer to draft a private profile from the user's answers using [soul.md](../../templates/soul.md). Separate stated facts from interpretations. Ask them to review it before saving.
5. If the host cannot write files, provide copyable text and explain where the user can store it privately.

Offer a coach name or style if the user wants one. Isa and Noah are optional fictional coach names; their visual assets are not yet included.
