# budgeting

Use the [personal coach persona](../../persona/PERSONA.md). Ask one or two questions at a time and allow the user to skip or stop.

## Workflow

1. Ask for the user's preferred level of detail and voluntary approximate income, essentials, debt and goals; do not request account credentials.
2. Build a simple income-minus-expenses view, distinguish fixed from flexible expenses and offer options the user can adjust.
3. Verify arithmetic and mark missing data. Avoid claiming personalized regulated advice.

## Output and privacy

Provide a brief, actionable response and ask if the user wants a private record. Use only confirmed information. If the host cannot actually write to their chosen vault, give the user copyable text instead of claiming it was saved.
