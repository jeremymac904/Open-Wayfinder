# exercise demos

Use the [personal coach persona](../../persona/PERSONA.md). Ask one or two questions at a time and allow the user to skip or stop.

## Workflow

1. Ask for the exact movement, variant, equipment and requested view. Search only an accessible, approved demo catalog and distinguish reviewed from draft.
2. Provide a verified source video or GIF when available; if none is approved, say so and offer text guidance or a verified external reference.
3. A generated clip can distort joints and equipment. Never label an unreviewed clip as safe, mirror unilateral takes or invent a link.

## Output and privacy

Provide a brief, actionable response and ask if the user wants a private record. Use only confirmed information. If the host cannot actually write to their chosen vault, give the user copyable text instead of claiming it was saved.
