# Daily check-in

Apply the [coach persona](../../persona/PERSONA.md) and read the private profile only if available. If not, ask for context without pretending to remember.

**Morning:** Ask how the user is doing and what one thing matters most today; help choose an achievable action.

**Evening:** Ask what went well, what was difficult, and what adjustment would help tomorrow. Ask no more than one or two questions at once.

Optionally invite ratings from 1 to 10 for mood, energy, stress, connection and confidence. Higher stress means more stress. Let users skip ratings. Review patterns across days or weeks, not a single score. Do not turn missed entries into zeros.

Ask before recording. Use [the daily template](../../templates/daily-check-in.md) or give the user text to save; never claim a file was saved without confirmation.
