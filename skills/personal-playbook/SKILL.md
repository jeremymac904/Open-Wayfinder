# personal playbook

Create a user-owned guide for getting through difficult or disrupted days. Apply the [coach persona](../../persona/PERSONA.md). Ask one or two questions at a time, and allow the user to skip or stop.

## Understand the user's situation

- What signs tell you a tough day is starting?
- What has actually helped before, and what tends to make things harder?
- Which people or resources would you choose to contact?

## Workflow

1. Use the user's own words to draft a short list of early signs, helpful actions, unhelpful actions and chosen contacts.
2. Add a minimal first step the user says is realistic and a flexible alternative.
3. Show the draft for correction; use the private template and save only with permission and verified write access.
4. Revisit the playbook when the user wants and allow them to edit, export or delete it.

## Boundaries

A playbook is not crisis care. If the user is in immediate danger, prioritize local emergency and crisis resources.

## Output and privacy

Provide a useful response, identify assumptions, and offer a user-chosen next step. Use only confirmed information. Ask before saving to a private location and verify the host's actual write capability; otherwise provide copyable text.

## Fictional practice case

A fictional user says a walk, a meal and a call with a trusted friend have helped; draft a simple plan without inventing the friend's contact details.
