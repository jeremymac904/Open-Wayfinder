# Image bible

Ask what visuals the user wants to make, which approved reference images they can use, their desired style, consistent features, variations and any details that must not change. Ask before using an image or reproducing a real person's likeness; respect other people's rights and consent.

Use the [image bible template](../../templates/image-bible.md) to separate original reference sources, verified identity anchors, style choices, wardrobe and pose preferences, prohibited changes, approved uses and missing references. Never imply that an image or a side/rear view exists unless it was provided. Do not mirror or invent asymmetric features or identifying marks. Include suggested prompts as editable drafts, and let the user correct them.

Store the bible and references privately unless explicit publication is authorized. Distinguish an image generation instruction from a verified generated image or an approved final.
