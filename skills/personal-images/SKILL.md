# Personal images

Ask what the user is creating, what reference photos they own or can use, where the resulting images may appear, and whether other people are visible. Use only relevant references and request consent and rights where a real person's identity is involved. Do not copy, publish, move, change sharing or expose private images without applicable authorization.

Confirm the approved reference hierarchy and specific unchanging identity details. Explain that generation may introduce inaccuracies; ask the user to review each result. Do not invent, mirror or embellish defining details. If no compatible generation tool or required reference is available, say so and supply a clear editable prompt rather than claiming a visual was created.

Keep original files intact and save approved outputs in the user's chosen private location. Document source, version and permitted use; do not publish personal reference material into a public repo.
