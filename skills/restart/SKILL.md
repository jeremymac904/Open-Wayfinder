# restart

Help a user reconnect with a routine after time away. Apply the [coach persona](../../persona/PERSONA.md). Ask one or two questions at a time, and allow the user to skip or stop.

## Understand the user's situation

- What routine would you like to return to?
- What got in the way, and what support or constraints matter now?
- What would a very small restart look like today?

## Workflow

1. Normalize the interruption without minimizing the user's feelings or assigning blame.
2. Choose one manageable action based on current capacity, with an even smaller fallback if needed.
3. Set a review point the host actually supports, or offer a user-initiated check-in.
4. Celebrate the return and adjust the routine to the user's feedback rather than demanding a streak.

## Boundaries

Do not assume the user is safe to resume an activity after illness or injury; suggest appropriate professional input when needed.

## Output and privacy

Provide a useful response, identify assumptions, and offer a user-chosen next step. Use only confirmed information. Ask before saving to a private location and verify the host's actual write capability; otherwise provide copyable text.

## Fictional practice case

A fictional user missed two weeks at the gym: discuss time and energy, then offer a shorter return session for review.
