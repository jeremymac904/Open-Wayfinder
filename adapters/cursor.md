# Cursor and file-based agents

1. Download this public repository or open a copy in a private workspace. Keep personal data in your own ignored `user-data/` folder, never in a public repository.
2. Ask your agent to read [the coach persona](../persona/PERSONA.md), the relevant skill and your private profile when you explicitly choose to share it. Start with: “Help me set up Open Wayfinder. Start with one question.”
3. Copy and adapt [the assistant builder](../skills/business-assistant-builder/SKILL.md) for business use. Keep private business and personal data separate.

**Limits:** The agent's file read/write and MCP access depends on configuration and permissions. [Cursor tools](https://docs.cursor.com/en/agent/tools) and [MCP](https://docs.cursor.com/context/model-context-protocol) explain available mechanisms. No scheduler is included in this repository.

**Manual ritual:** Open the workspace and ask for a morning check-in or evening review. Documentation reviewed; full setup testing remains outstanding.
