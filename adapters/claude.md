# Claude setup

1. Start a conversation or create a Project if available to your account. Paste the [coach persona](../persona/PERSONA.md) into the conversation or project instructions.
2. Add the contents of the [onboarding guide](../skills/onboarding/SKILL.md), then say “Help me set up Open Wayfinder. Start with one question.” If you use a private profile, share only what you choose; uploaded project knowledge is not automatically a live writable file.
3. For a work assistant, copy the [business assistant builder](../skills/business-assistant-builder/SKILL.md) into a separate conversation or project.

**Limits:** Features, file size, connectors and permissions differ by plan and configuration. Check [Projects](https://support.anthropic.com/en/articles/9517075-what-are-projects) and [connectors](https://support.anthropic.com/en/articles/11817150-connect-your-tools-to-unlock-a-smarter-more-capable-ai-companion). Verify actual file access and save approved updates manually when necessary.

**Manual ritual:** Type “Let's check in” in the morning and “Let's review today” in the evening.
