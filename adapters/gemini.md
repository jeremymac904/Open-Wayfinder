# Gemini setup

1. Start a chat and paste the [coach persona](../persona/PERSONA.md); ask “Help me set up Open Wayfinder. Start with one question.” Depending on your account you may be able to create a reusable Gem or skill. Check [Google's current instructions](https://support.google.com/gemini/answer/15146780) and [transition notice](https://support.google.com/gemini/answer/18560919).
2. Keep the [personal profile](../templates/soul.md) in a private place and share only what you choose. Verify that any connected storage is genuinely readable and writable before relying on it.
3. Put the [assistant builder](../skills/business-assistant-builder/SKILL.md) in a separate work conversation to create a business assistant.

**Limits:** Features, scheduling, integrations and data policies vary. [Scheduled actions](https://support.google.com/gemini/answer/16316416) may be available for some users, but are not guaranteed by this kit. A file attachment is not necessarily a live vault.

**Manual ritual:** Start a morning chat with “Let's check in” and an evening chat with “Let's review today.” Documentation reviewed; end-to-end account testing remains outstanding.
