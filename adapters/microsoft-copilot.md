# Microsoft 365 Copilot setup

Start a conversation and paste [the coach persona](../persona/PERSONA.md). Ask for one setup question at a time. For work, use the [business assistant builder](../skills/business-assistant-builder/SKILL.md) and follow your organization's information handling rules.

**Limits:** Custom agents, connectors and actions depend on product, licenses, administrator settings and permissions. [Copilot connectors](https://learn.microsoft.com/en-us/microsoft-365/copilot/connectors/overview) and [Copilot Studio connector tools](https://learn.microsoft.com/en-us/microsoft-copilot-studio/advanced-connectors) describe distinct options. A connected knowledge source does not automatically provide write access. Test a permitted read and an authorized write separately, or copy confirmed updates manually.

**Manual ritual:** Start a new conversation for a morning check-in or an evening review. Documentation reviewed; end-to-end testing remains outstanding.
