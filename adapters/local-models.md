# Local model setup

1. Choose a local model host and load the [coach persona](../persona/PERSONA.md) as a system instruction or at the start of a conversation. Start with: “Help me set up Open Wayfinder. Start with one question.”
2. Keep your profile privately. If the model has no file tool, paste only the context you want it to use and copy confirmed updates back manually.

**Limits:** A local model is not automatically private if its host sends data elsewhere; check its settings. File writes, tools, scheduling and model quality vary. Verify safety behavior and the relevant host documentation before relying on it.

**Manual ritual:** Open a conversation for morning and evening check-ins. No host-specific end-to-end test has been recorded.
